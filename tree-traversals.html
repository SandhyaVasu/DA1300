Tree Traversals

Visiting every node in a tree in a well-defined order is a traversal. The three depth-first orders — preorder, inorder, and postorder — differ only in when a node is visited relative to its children, and are usually written recursively. But each recursive call is really just an entry on an implicit call stack — run any of them below and watch an explicit stack stand in for that recursion. Level-order visits nodes breadth-first instead, one level at a time, using a queue in place of a stack.
