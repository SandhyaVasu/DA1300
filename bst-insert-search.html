The Binary Search Tree

A binary search tree keeps values ordered so that every node's left subtree holds only smaller values and its right subtree holds only larger ones. Both insert(x) and search(x) walk down from the root, comparing x against the current node and branching left or right — an operation whose cost is proportional to the tree's height. insert(x, node)
if node is None: return Node(x)if x == node.value: return node   # already presentif x < node.value: node.left  = insert(x, node.left)else:              node.right = insert(x, node.right)
search(x, node)
if node is None: return Falseif x == node.value: return Trueif x < node.value: return search(x, node.left)else:              return search(x, node.right)
