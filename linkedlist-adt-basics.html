The Linked List ADT

A singly linked list holds a chain of nodes, each storing a value and a pointer to the next node, reachable only from head. insert_at_beginning(x) rewires one pointer and is O(1); insert_at_end(x) must first walk the whole chain to find the last node, so it's O(n); display() walks the chain the same way to collect every value.
