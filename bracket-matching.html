Bracket Matching with a Stack

Scan the string left to right. Every opening bracket ( [ { gets pushed. Every closing bracket ) ] } must match whatever is currently on top of the stack — pop it and continue if it does; if it doesn't, or the stack is already empty, the string is unbalanced. Anything that isn't a bracket is simply scanned over.
