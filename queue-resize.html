Growing the Queue: resize()

A fixed-capacity queue has to refuse enqueue once it's full. A dynamic array queue avoids that: when enqueue finds size == capacity, it first calls resize(2×capacity) — walking the existing elements out in front-to-back order into a new, larger array starting at index 0 — and only then inserts the new value. This queue starts at capacity 4 (not ArrayQueue's default 10) so a resize is only a few enqueues away.
