Topological Sort (DFS-based)

A topological sort linearly orders the vertices of a directed acyclic graph (DAG) so that every edge u→v has u appearing before v. The DFS-based algorithm runs DFS and uses postorder processing: a vertex is pushed onto a stack only after all of its outgoing edges have been fully explored. Reversing that stack at the end yields a valid topological order — because a vertex is only ever marked finished after everything it points to.
